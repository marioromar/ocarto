# Ocarto v1.125 (v225)

Se añade **Estampar símbolo** para colocar repetidamente un símbolo puntual dentro de una zona delimitada:

- Acepta un área editable recta, una línea cerrada o varias líneas rectas conectadas que formen un perímetro.
- Con el símbolo puntual activo, cada toque o clic coloca un objeto independiente. Arrastrar estampa copias espaciadas dentro del recinto.
- Respeta los límites y huecos de un área; los clics fuera del recinto no crean objetos.
- Conserva el contorno y permite deshacer cada gesto. El botón termina el modo de estampado.

Verificación: pruebas de construcción de perímetros con segmentos unidos, cierre, inclusión de puntos y exclusión de huecos; suite completa y sintaxis de scripts.
