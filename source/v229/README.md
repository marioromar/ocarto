# Ocarto v229 interface modules

This branch contains the v229 workspace layout modules. The complete runnable project, including all existing mapping and LiDAR features, is delivered in `ocarto-v229-final.zip`.

To apply these modules to the app, load `interface-v229.css` after the existing page styles and load `interface-v229.js` after the existing feature scripts. The module preserves existing controls and reorganizes them into drawing tools, a central map, and dock tabs for symbols, layers, properties, and LiDAR.
