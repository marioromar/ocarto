# Ocarto v230

The runnable Ocarto build and all existing project files are in the matching `ocarto-v230-final.zip` release. This Git branch records the v230 implementation modules and tests.

New actions: select a line and one or more point symbols, then use **Duplicar y repartir** and enter the spacing; or select street line(s) and building areas, then use **Alinear edificios a calle**. **Medir selección** remains available for line lengths, polygon areas and perimeters.
