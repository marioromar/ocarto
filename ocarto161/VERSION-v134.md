# Ocarto v1.34

- Añadida la herramienta **Cambiar símbolo** en la barra de edición, inmediatamente después de Copiar/Pegar.
- Añadidas **Girar** y **Reverso** junto a ella.
- Cambiar símbolo aplica el símbolo activo a la selección compatible y omite referencias protegidas o geometrías incompatibles.
- Girar admite un ángulo en grados y conserva el historial de deshacer/rehacer.
- Reverso invierte el sentido de líneas y anillos de áreas, incluidos sus huecos.
- Expuesta la API interna del editor para que las herramientas avanzadas cargadas después funcionen sobre el mismo estado del mapa.
- Corregido el cierre del script de validación de geometrías.
