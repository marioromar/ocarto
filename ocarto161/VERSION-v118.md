# Ocarto v1.18

Herramientas avanzadas de edición de líneas:

- Módulo geométrico reutilizable para crear líneas paralelas a distancia exacta.
- Reversión segura del sentido de una línea para controlar el lado del desplazamiento.
- Integrado en la página para futuras acciones de paralela, offset y bordes de elementos.
- La geometría original se conserva; las operaciones son candidatas editables.
