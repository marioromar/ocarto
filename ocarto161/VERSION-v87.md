# v87 — Envío por selección desde plantilla

Nuevo modo «Enviar plantilla al mapa»: al activarlo, cada entidad de una capa de referencia que se toca se copia una sola vez a la capa activa del mapa de trabajo. Al tocar fuera, pulsar Escape o volver a pulsar el botón, termina la selección de envío. Los objetos originales de referencia permanecen intactos.

Verificación: `npm test` y análisis sintáctico de scripts.
