# v89 — Tamaño visual independiente de la plantilla

Cada capa vectorial de plantilla tiene un control para reducir el tamaño visual de sus símbolos y evitar que tapen detalles. Solo cambia la vista de referencia; al enviar entidades al mapa de trabajo, se aplican el tamaño y grosor definidos por el mapa general.

Verificación: `npm test` y análisis sintáctico de scripts.
