# Ocarto v1.06 — Selección de clases guía OCAD

- Cada plantilla OCAD muestra casillas para elegir qué clases de vegetación pueden aportar ejemplos a la IA.
- La selección se guarda en la capa del proyecto; se pueden tener varias plantillas con configuraciones independientes.
- Las áreas desmarcadas siguen visibles como plantilla, pero no participan en la inspección ni en el entrenamiento.
- Prueba de regresión para el filtrado de símbolos guía; se mantienen las pruebas de importación OCAD real/sintética de v1.05.
