# v86 — Elegir plantilla o mapa editable

Al aceptar detecciones LiDAR ahora se puede elegir el destino: guardar en capas de referencia para revisar/copiar, o abrirlas directamente como objetos de mapa editables. Las capas de referencia también ofrecen «Hacer editable».

Verificación: `npm test` y comprobación sintáctica de scripts.
