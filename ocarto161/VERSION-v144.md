# Ocarto v1.44

## Agrupar y desagrupar

- Agrupa dos o más objetos editables y conserva el grupo al guardar el proyecto.
- Selecciona un grupo completo para moverlo o aplicar operaciones masivas.
- Desagrupa desde una selección parcial o completa.
- Respeta bloqueos, símbolos protegidos y capas de referencia.
