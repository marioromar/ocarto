# v77 — Mínimos ajustados con áreas marcadas

Al terminar un modo de marcado, el ajuste automático usa las superficies marcadas para conservar y quitar. Calcula por separado el área y el ancho equivalente: si las medidas de ambas clases se pueden separar, coloca el mínimo entre el mayor valor quitado y el menor valor conservado.

Si las marcas se solapan en una medida, mantiene el mínimo configurado para esa medida. Las decisiones manuales de conservar o quitar siguen teniendo prioridad para las superficies marcadas. Si solo hay superficies quitadas y ninguna conservada, no modifica los mínimos.
