# v90 — Importar mapas vectoriales como plantilla

GeoJSON, KML, KMZ y DXF se pueden importar al mapa editable como antes o añadir como capas vectoriales de plantilla de referencia sin sustituir la cartografía de trabajo. Las capas de referencia aparecen en el selector «Enviar plantilla al mapa» y conservan una escala visual independiente para sus símbolos.

Verificación: `npm test` y análisis sintáctico de scripts.
